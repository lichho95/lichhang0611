# Bắt đầu trong 5 phút

1. Giải nén source ZIP.
2. Chạy `npm install` và `npm run dev`.
3. Mở `http://localhost:5173/` trên trình duyệt.
4. Mở `src/wedding.config.ts` để đổi **tên, ngày cưới, ảnh, địa điểm, nhạc, thông tin QR**.
5. Xem `docs/IMAGE_GUIDE.md` để biết kích thước ảnh từng vị trí.
6. Khi hoàn tất, chạy `npm run build`, sau đó deploy Cloudflare Pages. Muốn lưu RSVP/lời chúc thật thì phải liên kết D1 (đọc README.md).

**Mọi tên/ảnh hiện tại là minh hoạ.** Hãy kiểm tra lại toàn bộ thông tin trước khi gửi cho khách mời.
